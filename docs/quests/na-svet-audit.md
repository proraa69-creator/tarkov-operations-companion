# «На свет» (To the Light): аудит и добавление в базу квестов

Запрос владельца, 15.10.2026: «еще в нашей базе нету серии квестов "на свет" нужно изучить на ресурсах, найти всю инфу по квестам, точки выполнения, требования итд и добавь в нашу базу что бы отображалось в приложении».

Данные собраны 15.10.2026. Код — `src/data/curatedQuests.ts`, тесты — `src/data/curatedQuests.test.ts` и `server/src/services/questBase.test.ts`.

## Что это за серия

- **«На свет»** (англ. **To the Light**) — цепочка заданий **Механика**, которая ведёт к **Смотрителю** (Lightkeeper). 11 заданий: 10 у Механика и одно у Миротворца («На свет. Фиаско»).
- Добавлена в игру в версии **1.1.5.0.47242**: в русской вики все страницы серии стоят в категории «Квесты патча 1.1.5.0.47242». Сама версия вышла около 8–10 сентября 2026 г. вместе с переделкой Маяка. По сторонним гайдам, старый путь к Смотрителю («Сетевой провайдер», «Загладить вину») она заменила. В tarkov.dev этих старых заданий тоже больше нет.
- Последнее задание серии, «На свет. Новое знакомство», — это старое задание Механика «Новое знакомство» (Getting Acquainted, игра 0.13), переименованное и переделанное. У него тот же id игры: `625d700cc48e6c62a440fab5`.
- Это постоянная линия торговца. К событиям (KORD BREACH) и сюжетным главам она не относится.
- Для Каппы не нужна: во всех источниках «Не нужен» / `reqkappa: No`. Нужна для Смотрителя: после неё открывается его первое задание «Источник информации».
- Владелец уже брал первое задание серии. В его логах (`audit/log-audit.txt`, `src/progression/__fixtures__/owner-logs-2026-09.json`) есть запись `18.09.2026 23:56:45 t10 6a880acc9216d0f5aa078305` (игра 1.1.5.1, PvP, «задание взято»). До этой правки приложение не знало этот id.

## Почему серии не было в базе

1. **В tarkov.dev её нет ни в одном режиме.** Файлы `json.tarkov.dev/regular/tasks` (504 задания), `pve/tasks` (500) и `pvp-season/tasks` (463) прочитаны 15.10.2026. Ни одного из 11 id в них нет. В словарях `regular/tasks_ru` и `tasks_en` осталось только название `625d700cc48e6c62a440fab5 name` = «На свет. Новое знакомство» / «To the Light - Getting Acquainted». По нему и видно, что id последнего задания — игровой. Описаний и целей в словарях нет. GraphQL `api.tarkov.dev` 15.10.2026 отвечал «GraphQL server unavailable». У «Источника информации» (`63966faeea19ac7ed845db2c`) в tarkov.dev `taskRequirements: []`: ссылка на предыдущее задание пропала вместе с ним.
2. **Наш код ничего не отфильтровывал.** `src/data/catalogSource.ts:62` загружает файл заданий режима, а `adaptTasks` (`catalogSource.ts:334`, `:342` … `:441`) переводит в задания приложения каждую запись. Фильтров по событию, типу или режиму там нет. Слияние сюжетных глав (`addMissingStoryChapters`) эти id тоже не трогает. Сервер собирает свою базу тем же кодом (`server/src/services/catalogService.ts` → `fetchLiveCatalog`), так что и на сервере серии не было.
3. **Под другим именем серии тоже не было.** Старое «Новое знакомство» с тем же id было в прежних данных tarkov.dev (`audit/quest-audit.json`), но из текущих файлов пропало.
4. `docs/quests/quest-grid-report.md` (раздел «Есть на tarkov.help, нет в текущей игре», строки 164–174, 187) относит эти задания к «истории». Это неверно: в игре они есть, их нет только в tarkov.dev. Отчёт сетки генерируется скриптом `scripts/quest-grid-snapshot.mjs`, и в этой правке он не менялся.

## Как серия добавлена

`src/data/curatedQuests.ts` (`TO_THE_LIGHT`, `withCuratedTasks`, `applyCuratedQuestNotes`):

- Сразу после загрузки файла заданий (`catalogSource.ts:73`) кураторские задания добавляются в него **в форме tarkov.dev** и на языке каталога. Дальше они проходят те же адаптеры, что и все остальные: список «Все» и фильтр по торговцу, вкладки торговцев, карточка задания, «что взять в рейд», точки на карте (`adaptLiveMapMarkers`, `catalogSource.ts:96`), поиск по id в логах игры.
- Если tarkov.dev снова начнёт отдавать задание с тем же id, это задание берётся из tarkov.dev. Кураторская запись не добавляется и не перезаписывает его.
- Задание добавляется, только если в файле торговцев режима есть его торговец.
- Если в tarkov.dev у «Источника информации» нет предыдущего задания, ему снова ставится «На свет. Новое знакомство» (так у tarkov.help и в английской вики).
- После общей обработки (`catalogSource.ts:91`) добавленным заданиям проставляется кураторское описание: как открывается задание, что взять, каких точек нет. Ещё добавляются другие названия (`ocrAliases`), предметы для целей `useAny` (сигнал, транспондер) и строки наград, которых нет в форме заданий: стартовое снаряжение, репутация, крафт.
- Режимы: **PvP, PvE и Сезон**. В tarkov.dev задания Смотрителя, которые открывает эта серия, есть во всех трёх режимах (14 / 14 / 13). Вики ограничений по режимам не указывает. tarkov.help пишет «PVP», но он вообще ведёт только PvP: у «Источника информации» и «Загладить вину» там тоже стоит только PVP.
- Сервер (`server/src/services/questBase.ts`) строит обе версии базы, RU и EN, тем же кодом. Названия `nameRu` / `nameEn` берутся из каталога каждого языка. Код базы не менялся. Серия появится на сервере при следующей сборке базы после деплоя (каждые 30 минут).

## Чего нет в источниках

**Точки на карте.** Ни один источник не даёт их координат, поэтому точек нет:
- серверная у зоны испытаний оружия в Лаборатории (№1);
- место для Wi-Fi камеры в магазине «Местный» на Таможне (№2);
- четыре места подавителей (№4): метеовышка и будка на лесопилке на Лесу, стройка на Таможне, архив санатория на Береге;
- места флешки V3 (№11) — шале и коттеджи базы Отступников после переделки Маяка. В вики есть только скриншоты. Карта tarkov.help (`/map/lighthouse/filter/quest/1066`) доступна только по премиум-подписке и не читалась. Старые точки tarkov.dev (водоочистная) после переделки неверны, поэтому не используются;
- здание Маяка, «Посетить здание Маяка» (№11).

Точки других заданий в тех же местах (например, «Устойчивый сигнал» на метеовышке) намеренно не переносились. Совпадение места по скриншоту — это не координаты этой цели.

**Предметы без id.** «Жёсткий диск с дезой» (№1) и «амулет от Смотрителя» / «улика» (№6, №7) — квестовые предметы новой версии. В файлах tarkov.dev (`items`, `questItems`) их нет, поэтому иконок у них нет.

**Id целей.** Игра их не публикует. У кураторских целей стабильные свои id вида `<id задания>-objective-<n>`. Сами задания в логах находятся по id задания.

**Где источники расходятся.** В приложение взяты данные, на которых сходится большинство источников:
- Лояльность для №1. Вики EN не называет Прапора.
