# Сетка квестов: tarkov.dev, tarkov.help и приложение

Снимок от 2026-10-12. Собран скриптом `node scripts/quest-grid-snapshot.mjs`; данные для приложения — `src/data/questGrid.snapshot.json`.

## Главное

- **Как игра открывает квесты сейчас.** 168 квестов открываются **ветками торговцев по уровням** (у каждого из семи основных торговцев 3–4 ветки, по одной на уровень лояльности; внутри ветки — уровни 1…5), 12 — **в диалоге** с торговцем (первые задания), 203 — по цепочке (предыдущий квест), 99 — по лояльности. До этой версии приложение ветки и диалоги не читало и считало такие квесты доступными с 1-го уровня.
- **tarkov.help** знает 554 квеста (только PvP): 459 сопоставлены с игрой, 95 — история (удалённые цепочки, события KORD BREACH, сюжетные главы). 34 квеста игры на tarkov.help нет.
- **Каппа:** tarkov.dev отмечает 13 квестов, tarkov.help — 128 (это старый список).
- **Уровень персонажа** расходится у 71 квеста: в новой системе их открывают ветки и лояльность, а не уровень.
- **PvP / PvE / Сезон:** сетка одинаковая, кроме квестов Арены ([PVP ZONE] / [PVE ZONE]) и нескольких условий (раздел в конце).

## Как приложение теперь считает статусы

1. **Логи игры** — правда: взято, сдано, провалено.
2. **Цепочка:** всё, что требует квест из логов, выполнено.
3. **Ветка:** квест из логов на N-м уровне ветки показывает, что ветка дошла до N. Её квесты уровней ниже — «вероятно выполнено», того же уровня — открыты, выше — «откроется на N-м уровне».
4. **Лояльность:** квест из логов на уровне лояльности N (его ветка или требование) показывает, что этапы торговца ниже N пройдены — их квесты «вероятно выполнено».
5. **Старт:** первые (диалоговые) квесты торговца пройдены, если в логах есть его более поздний квест.
6. Пункты 3–5 работают, только если история игрока началась раньше самых старых логов (квест из логов требует то, чего в логах нет). Новый аккаунт или вайп целиком в логах — тогда ничего не додумывается. «Оружейник» — только по логам. Квесты другой фракции, выше уровня персонажа и «ветвления» (открываются взятием или провалом другого квеста) не додумываются никогда.

## Как квесты открываются в текущей версии игры

В данных tarkov.dev у квестов теперь есть условия вне цепочек (`otherRequirements`): **ветка торговца и её уровень** (глобальная переменная игры, «уровень ≥ N») и **диалог с торговцем** (стартовые квесты). До этой версии приложение их не читало и показывало такие квесты доступными с 1-го уровня.
