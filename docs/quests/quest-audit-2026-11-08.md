# Сверка квестов: игра и наша база

08.11.2026. Квесты, их условия и награды игра получает со своего сервера и на диске не хранит: в её папках только иконки квестов. Поэтому сверены данные, выгруженные из самой игры (tarkov.dev, PvP — 503 квеста, PvE — 499), между режимами и с tarkov.help, который ведут вручную по каждому патчу (сопоставлено 438 квестов PvP). Приложение показывает квесты по этим данным игры и по нашим правкам (раздел 4).

- **Добавленные квесты**, которых нет в данных игры у tarkov.dev: серии «На свет», «Смещение баланса», «БТР на Маяке», «Борей» («За проезд передаём!»), «Вторжение Scourge», «Хеллоуин 2026», «Новое начало» для PvE (престиж 2–4).

- **Правила приложения**: квест «Новое начало» открыт только на своём престиже; квесты Водителя БТР добавляются сами, когда выполнены их условия (игра не пишет их в логи); зоны «Устранений» нарисованы чуть меньше игровых.
