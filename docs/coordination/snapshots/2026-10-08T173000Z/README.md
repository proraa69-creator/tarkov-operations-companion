# RaidOS: пакет синхронизации Codex и Claude

Актуальный продукт: Raid OS, помощник для Escape from Tarkov. Это НЕ проект WOD.

Пакет подготовлен по живому серверу и исходникам 8 октября 2026 года, часовой пояс Asia/Bangkok. Машиночитаемое время снимка находится в `source-manifest.json`.

## С чего начать

1. Claude читает `CLAUDE_START.md`, затем `PROJECT_STATE.md` и `WORK_QUEUE.md`.
2. Оба агента соблюдают `COORDINATION.md`, ведут `WORK_LOG.md` и не редактируют одновременно одни и те же файлы.
3. Ветка `sync/codex-claude-context` уже содержит snapshot-код: повторно накладывать архив на неё не нужно. Для восстановления из ZIP нужна чистая копия основного репозитория на точном базовом коммите из `source-manifest.json`, затем содержимое `source-overlay.tar.gz`.
4. Не накладывать архив на рабочую папку с чужими изменениями. Не выполнять `git reset --hard`, `git clean` или force-push.

## Содержимое

- `PROJECT_STATE.md`: архитектура, сервер, версии, настройки, выполненные изменения и ограничения.
- `WORK_QUEUE.md`: приоритеты и критерии проверки; предложение распределения работы, не запущенные задачи.
- `COORDINATION.md`: порядок совместной работы, синхронизации и безопасного выпуска.
- `AUTOMATIC_RELEASES.md`: рабочий CI-gated выпуск через `release/production`, без доступа Claude к SSH.
- `CLAUDE_START.md`: готовое вводное сообщение для Claude.
- `source-manifest.json`: точный коммит, хэши файлов, публичная версия, состояние API.
- `source-overlay.tar.gz`: только изменённые/новые исходники действующей серверной рабочей копии.
- `tracked-changes.patch`: дополнительный diff только отслеживаемых Git файлов. Новые файлы есть в архиве; один этот diff неполон.
- `evidence/`: результаты проверок и макеты без данных реальных пользователей.

## Важно

GitHub `main`, локальная старая папка и опубликованный EXE сейчас не эквивалентны. Серверная рабочая копия содержит незакоммиченные изменения. Метка опубликованной сборки не является отдельным Git-коммитом.

В пакет не включены пароли, токены, приватные ключи, `.env`, база аккаунтов, WAL/SHM, журналы и EXE. Публичный ключ подписи в исходниках не является секретом. Проверка известных форматов секретов выполнена, но не является универсальным аудитом.

Связь с Claude не устанавливается одним архивом. Claude должен получить пакет или доступ к общей папке/ветке; в этом сеансе прямого подключённого канала сообщений Claude нет. До начала работы Claude должен подтвердить базовый коммит, сборку и список файлов, которые берёт в работу.
