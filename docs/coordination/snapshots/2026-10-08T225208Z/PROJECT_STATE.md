## Последний выполненный ремонт

### Автообновление ПК

Две независимые настройки: «Уведомлять о наличии нового обновления» и «Автообновление». Сохраняются старые ключи `autoCheck` и `autoInstall` с новой семантикой.

- Автоустановка имеет одну возможность при запуске приложения, после начальной проверки примерно через 3 секунды.
- Во время использования каждые 5 минут проверяются только метаданные, если уведомления включены. Обновление не скачивается автоматически.
- Новая версия даёт кнопку «Обновить приложение» справа сверху; загрузка открывает окно прогресса.
- Автообновление не запускается в рейде. Состояние рейда проверяется перед скачиванием и перед заменой EXE. Если рейд начался позже, проверенный файл сохраняется для ручной установки, автоматическая установка после рейда не ставится в очередь.
- Проверяются доверенный HTTPS-источник, edition, подпись Ed25519, размер и SHA-256. Клиент не принимает произвольный сервер обновлений из пользовательского поля.
- Нет установки на закрытии приложения. Не смешивать эту проверку ПК с отключённым агентом деплоя сервера.
- Битые/оборванные загрузки закрывают stream, убирают частичный файл и допускают повтор.
- Пользователю старой сломанной версии может понадобиться одна ручная загрузка нового EXE.

Файлы: `electron/appUpdate.ts`, `electron/main.ts`, `src/components/AppUpdateSettings.tsx`, `src/components/UpdateButton.tsx`, `src/styles/updateOverlay.css`, `src/electron.d.ts`.

### Сюжетные задания

В интерфейсе показываются реальные главные и опциональные задания, прочитанные с открытого игрового экрана, а не список будущих пронумерованных этапов. Только главы, обнаруженные у этого аккаунта, должны быть видны в сюжетном разделе; сюжетные не должны дублироваться в обычных текущих.

Снимок наблюдаемых заданий сохраняется как `storyObjectives`. Сохраняются проверки этапов и двухкадровое подтверждение переходов; список видимых целей обновляется раньше, без ожидания подтверждения перехода. Нельзя засчитать будущую цель по одному общему слову или нечёткой OCR-строке.

Кнопка карты у каждой незавершённой распознанной цели с известной привязкой; несколько карт дают отдельные ссылки. Для неизвестной цели показывать текст без выдуманных координат. Internal stageIndex остаётся внутренним ключом привязок, не пользовательским номером этапа.

Добавлен фильтр нижнего меню EFT и невалидных OCR-счётчиков вроде `6/3`. Опрос сюжетного экрана около 600 ms. Требование владельца: от открытия страницы задания до синхронизации не более 10 секунд и без перескакивания. Это ещё не доказано для каждого живого ПК; старый offline benchmark двух OCR-кадров был около 9.65 секунд.

Ключевые файлы: `StoryScreenScanner.tsx`, `import/storyObjectives.ts`, `import/storyScan.ts`, `StoryObjectivesPanel.tsx`, `progression/storyObjectives.ts`, `QuestsPage.tsx`, `MapsPage.tsx`, `data/storyChapterSeeds.ts`, `data/storyQuestIndex.ts`.
