# Сервер на ноутбуке (постоянно включён)

Ноутбук держит включёнными API-сервер, сайт с личным кабинетом и публичную ссылку для друзей.
Отдельно ставить ничего не нужно: это тот же exe приложения, запущенный в режиме сервера
(`--server-mode`). Игровые функции (оверлеи, чтение экрана, горячие клавиши) в этом режиме выключены,
запрос прав администратора не появляется, окно запускается свёрнутым.

## Две версии приложения

С версии, где появился вход в аккаунт, собираются два разных exe (`electron/buildEdition.ts`):

- **Версия владельца** (`OWNER_BUILD=1`): «Аккаунт сервера», кнопка «Сервер» в верхней панели, сервер и сайт на
  этом компьютере, ссылка для друзей, оплата, стримеры. Её запускают на ноутбуке-сервере и на вашем игровом ПК.
- **Версия для игроков** (по умолчанию): при первом запуске окно входа в аккаунт, в профиле «Личный кабинет».
  Никаких настроек сервера в ней нет, ключи `--server-mode`, `--enable-local-server` и `--enable-tunnel` она
  игнорирует. Адрес сервера вшит при сборке: `https://raidos.app` (или `TARKOV_DEFAULT_SERVER_URL`).

Кнопка «Скачать для Windows» на сайте отдаёт **только версию для игроков**. Её кладёт рядом с сервером
`Server-Laptop-Setup.cmd`: `%LOCALAPPDATA%\TarkovOperatorServer\client\Tarkov Operator <версия>.exe` и
`client\version.json`. Если этой папки нет, сайт отвечает «Версия приложения для игроков ещё не опубликована»:
exe владельца чужим людям не раздаётся. Версия владельца не обновляет себя версией для игроков
(`/download/version.json` сообщает `edition: "client"`).

## Установка

1. Скачайте на ноутбук все части `TarkovOperator.part*` (версия владельца), `TarkovOperatorClient.part*` (версия для
   игроков) и `Server-Laptop-Setup.cmd` в одну папку.
2. Запустите `Server-Laptop-Setup.cmd`. Скрипт:
   - собирает exe владельца в `%LOCALAPPDATA%\TarkovOperatorServer\Tarkov Operator Server.exe`;
   - собирает версию для игроков в `%LOCALAPPDATA%\TarkovOperatorServer\client\` и пишет рядом `version.json`
     (это и есть «загрузить файл для клиента на сайт»);
   - проверяет контрольные суммы;
   - запускает сервер с `--server-mode --enable-tunnel`.
3. Приложение запускает сервер (порт 8787), сайт (порт 5202) и публичную ссылку `https://….trycloudflare.com`.
   Ссылку видно в свёрнутом окне: кнопка «Сервер» в верхней панели.

Настройки ноутбука (их меняете вы сами, скрипт их не трогает):

- Параметры → Система → Питание: «Переводить в спящий режим» — «Никогда» (при питании от сети).
  Иначе сервер засыпает вместе с ноутбуком.
- Действие при закрытии крышки — «Ничего не делать», если ноутбук будет стоять закрытым.
- Автозапуск при включении Windows (по желанию). Нажмите Win+R, введите `shell:startup` и создайте в
  открывшейся папке ярлык на `%LOCALAPPDATA%\TarkovOperatorServer\Tarkov Operator Server.exe`.
  В свойствах ярлыка допишите к объекту ` --server-mode --enable-tunnel`. Чтобы отключить автозапуск,
  удалите ярлык.

## Перенос базы с основного ПК

База одна, это файл SQLite в папке данных приложения:

```
%APPDATA%\Tarkov Operator\server\companion.sqlite
```

Если на ПК есть старая папка `%APPDATA%\Tarkov Operations Companion Beta`, база лежит в ней: `server\companion.sqlite`.

Как перенести базу:

1. На основном ПК закройте приложение. Сервер остановится, и база закроется.
2. Скопируйте `companion.sqlite` на флешку. Если рядом лежат `companion.sqlite-wal` и `companion.sqlite-shm`,
   скопируйте и их.
3. На ноутбуке закройте Tarkov Operator Server.
4. Положите файлы в `%APPDATA%\Tarkov Operator\server\` с заменой и запустите сервер снова.
5. На основном ПК выключите «Сервер и сайт на этом компьютере» (кнопка «Сервер»). Иначе будут два сервера
   с разными базами.

Аккаунты, стримеры, прогресс и отметки хранятся только в этой базе. Её не удаляют ни обновление, ни замена exe.

## Как проходит обновление

Код меняется не на ноутбуке, а в репозитории. Порядок такой:

1. Правки делаются в Claude Code и попадают в GitHub.
2. Из репозитория собирается новый exe.
3. На ноутбук кладутся новые части и новый `Server-Laptop-Setup.cmd`.
4. Запускается `Server-Laptop-Setup.cmd`. Скрипт:
   - закрывает работающий сервер штатно, база закрывается корректно;
   - заменяет exe и снова запускает сервер.

Простой около минуты. База остаётся. Друзья после обновления сервера могут скачать новый exe на сайте:
кнопка «Скачать для Windows» отдаёт версию для игроков из папки `client`.

Перед крупными обновлениями сделайте копию базы. Для этого закройте сервер и скопируйте `companion.sqlite`
в другое место.

## Автообновление приложения у игроков

Приложения, подключённые к серверу ноутбука (Профиль → «Адрес сервера»), обновляются сами:

- при запуске и затем раз в 6 часов приложение спрашивает сайт ноутбука (`/download/version.json`), какая
  сборка версии для игроков там лежит (версия владельца её не ставит);
- если она новее, в верхней панели появляется кнопка «Обновить приложение»;
- по нажатию новый exe скачивается рядом со старым и проверяется по размеру и SHA-256. Затем приложение
  закрывается, файл заменяется, и запускается новая версия. Настройки и прогресс сохраняются.

Значит, для обновления у всех достаточно обновить ноутбук (`Server-Laptop-Setup.cmd`). Сам ноутбук и копия,
которая запускает свой сервер (`127.0.0.1`), себя не обновляют. На основном игровом ПК впишите в
«Адрес сервера» постоянный адрес ноутбука, тогда он тоже будет получать обновления.

Автообновление работает, начиная с версии, в которой оно появилось: её один раз ставят вручную.

## Постоянный адрес (Cloudflare Tunnel)

Бесплатная быстрая ссылка (`trycloudflare.com`) меняется при каждом запуске сервера. Постоянный адрес даёт
туннель с именем в вашем аккаунте Cloudflare.

Важно понимать, как это работает. На Cloudflare **ничего не загружается**: сервер, сайт и база остаются на
ноутбуке. Cloudflare только держит постоянный адрес (например `https://tarkov.ваш-домен.ru`) и пересылает
запросы на ноутбук через защищённое соединение. Открывать порты на роутере не нужно. Выключен ноутбук —
выключен и сайт.

Что нужно от вас (аккаунт и покупку домена делаете вы сами):

1. Бесплатный аккаунт на https://dash.cloudflare.com.
2. Свой домен, добавленный в Cloudflare. Его можно купить прямо в Cloudflare (Domain Registration),
   от ~$10 в год, или перенести туда DNS уже имеющегося домена.
3. Создайте туннель: Zero Trust → Networks → Tunnels → Create a tunnel → тип **Cloudflared** →
   имя, например `tarkov-laptop`. Ставить cloudflared по инструкции на странице не нужно: приложение само
   скачивает и запускает его.
4. На той же странице есть команда установки с длинным токеном `eyJ…`. Скопируйте её целиком или только
   токен. **Токен — это пароль туннеля**: не отправляйте его в чат и никому не показывайте. Если он
   утёк, удалите туннель и создайте новый.
5. Добавьте публичный адрес: Public Hostname → Add:
   - Subdomain `tarkov`, Domain — ваш домен;
   - Service: тип `HTTP`, URL `127.0.0.1:5202`.
6. На ноутбуке разверните окно Tarkov Operator Server → кнопка «Сервер» → «Постоянный адрес» → «Настроить».
   Введите адрес (`tarkov.ваш-домен.ru`), вставьте токен и нажмите «Сохранить». Токен хранится на ноутбуке
   в зашифрованном виде (DPAPI Windows).
7. Когда в строке «Ссылка» появится «работает», адрес готов. Друзья открывают его в браузере. В приложении
   они вписывают его один раз: Профиль → «Адрес сервера». После перезапусков и обновлений адрес не меняется.

Убрать постоянный адрес можно кнопкой «Убрать»: приложение вернётся к бесплатной меняющейся ссылке.

### Если хочется совсем без ноутбука

Сервер можно перенести в облако Cloudflare: Workers + база D1, есть бесплатный лимит. Тогда он работает
круглосуточно, а обновление — это одна команда публикации. Но код сервера для этого нужно переписать
(сейчас он использует `node:sqlite` и работает как обычная программа), это отдельная большая задача.
