# Настройка Lava.top через сайт Raid OS

Раздел владельца: **Админ-панель → Настройки продаж → Оплата через Lava.top**.

Укажите offerId, валюту USD/EUR, курс для статистики и способ оплаты. Цена месяца и других периодов задаётся в самом
оффере Lava.top; для текущего оффера месяц стоит $10. API-ключ и ключ вебхука вводятся **только в приложении на ноутбуке**.
Сайт показывает только наличие ключей. Его API отвергает поля ключей и команды удаления ключей.

Сайт передаёт изменения серверу с сессией подтверждённого владельца. Сервер отправляет их в главное приложение по
существующему каналу utility process. Приложение проверяет и сохраняет общие настройки в payments.json, существующие
ключи остаются в Electron safeStorage (на Windows — DPAPI), затем сервер применяет новую конфигурацию Lava без перезапуска. После
следующего запуска приложение передаёт те же настройки через окружение, как и раньше. Изменения записываются в журнал
действий без значений ключей. Посторонние пользователи получают 404, запрос без сессии — 401. Ответы не кешируются.

Без приложения владельца (standalone npm run server:dev) изменение оплаты через сайт недоступно. Перед вводом ключей
проверьте HTTPS и адрес сайта. Ключи почты/SMS, настройки ЮKassa и права владельцев этот раздел не меняет.

Для текущего сайта адрес вебхука — `https://raidos.app/v1/payments/lava/webhook`. В Lava.top должна быть выбрана
авторизация X-Api-Key или Basic с тем же ключом вебхука, который сохранён в Raid OS, и включены успешная/неуспешная
оплата, успешное/неуспешное продление и отмена подписки.

Кнопка **Проверить вебхук** запускает существующую безопасную проверку приложения: неизвестный контракт на локальном
сервере и проверка публичного адреса без ключа. Деньги не списываются и подписки не создаются. Эта проверка не доказывает
доставку событий из кабинета Lava.top. Для этого смотрите историю вебхуков Lava.top и «Платежи → События Lava.top».

## Обновление

Требуется пересобрать и установить **приложение-сервер вместе с сайтом**: новые API-маршруты и обработчики канала
приложения нужны одновременно с формой. Одной замены файлов сайта недостаточно. Сначала проверьте изменения в отдельной
сборке и сделайте резервную копию данных штатными средствами проекта. Изменения подготовлены отдельно в ветке
`codex/lava-web-settings`; рабочая ветка `claude/vibrant-ritchie-vy7uh2` не меняется.

Проверки: серверные тесты `src/routes/paymentSettings.test.ts`, регрессии оплаты и продления, typecheck сайта и Electron,
сборка сайта. Новые тесты проверяют доступ владельца, валидацию, отсутствие ключей в ответах и журнале, применение
конфигурации без перезапуска, ошибки хранилища и лимиты диагностики.


## ЮKassa

В той же вкладке владелец может сохранить shopId, цену месяца в рублях, чеки, долю стримера и разрешение автопродления. Секретный ключ вводится только в приложении на ноутбуке и не принимается веб-маршрутом. Сохранение проходит через тот же канал приложения, сохраняет ключ и настройки Lava, обновляет работающий сервер и оставляет запись аудита без секретов.

Адрес уведомлений: `https://raidos.app/v1/payments/yookassa/webhook`. В ЮKassa подключите события успешной оплаты и отмены платежа. Автоплатежи включайте после подключения повторных платежей для магазина. Проверки суммы, статуса и повторного получения платежа из API ЮKassa сохранены. Уже созданные платежи и суммы сохранённых автоплатежей не пересчитываются.

## Проверено в этой ветке

Все 171 серверных теста прошли (в Windows без изоляции процессов, с локальным TypeScript loader; loader не входит в изменения). Проверки типов сайта и Electron прошли, production-сборка сайта прошла. Общая проверка типов сервера также прошла. Исправлены прежние ошибки: HTTP-помощник ownerAdmin.test.ts теперь принимает тип ответа, а конфигурация сервера включает JSX и существующие декларации Electron/Vite для импортируемого общего кода. Сборка exe и реальный платёж не выполнялись.

В кабинете уже имеется отдельный магазин RaidOS: shopId 1481580, статус «Подключается». Для него сохранены HTTP-уведомления payment.succeeded и payment.canceled на https://raidos.app/v1/payments/yookassa/webhook. Магазин бота shopId 1457509 и его настройки сохранены. Новый магазин ещё должен завершить подключение ЮKassa; затем владелец вводит его ключ в приложении и выбирает цену в рублях. Цена ЮKassa в этой работе не назначена: $10 относятся к офферу Lava.top.
