# Вход и восстановление пароля по номеру телефона (SMS-коды)

Что умеет сервер, когда подключён SMS-провайдер:

- **Привязка телефона** в личном кабинете (сайт и приложение): номер + текущий пароль → код из SMS → номер
  подтверждён. Сменить номер — так же; отвязать — по текущему паролю. После регистрации на сайте предлагается
  необязательный шаг «Номер телефона» (его можно пропустить).
- **Вход по коду из SMS**: номер → код → вход. На сайте — кнопка «Войти по коду из SMS», в приложении — ссылка под
  формой входа.
- **Восстановление пароля** («Забыли пароль?»): номер → код → новый пароль. Все прежние входы на всех устройствах
  завершаются.

Пока провайдер не подключён, всё это скрыто: сайт и приложение показывают только вход по e-mail и паролю
(сервер сообщает `smsEnabled: false` в `GET /v1/accounts/auth-config`).

## Что нужно сделать владельцу

1. **Выбрать провайдера.** Поддерживаются три российских сервиса (все — оплата по факту отправленных SMS):
   - **SMS.ru** — проще всего: нужен только `api_id`. Регистрация на sms.ru → раздел «Программистам» →
     скопируйте `api_id`.
   - **SMSC.ru** — нужны логин и пароль (в настройках SMSC можно завести отдельный API-пароль — лучше его).
   - **SMS Aero** — нужны e-mail аккаунта и API-ключ: smsaero.ru → Настройки → API.
2. **Пополнить баланс** у провайдера (обычно от нескольких сотен рублей). Цена одной SMS на номера РФ — порядка
   нескольких рублей и зависит от оператора и имени отправителя; точные тарифы смотрите на сайте провайдера.
3. **Имя отправителя** (необязательно). Без своего имени SMS уходят с общим именем провайдера. Своё имя (например
   `RaidOS`, до 11 латинских букв и цифр) нужно сначала **согласовать у провайдера**: операторы связи регистрируют
   буквенные имена отдельно, обычно это занимает несколько дней и может стоить отдельную абонентскую плату.
   Пока имя не согласовано, оставьте поле пустым — иначе SMS не будут доставляться.
4. **Ввести настройки на ноутбуке-сервере** (только там!): приложение Raid OS Server → кнопка «Сервер» →
   «Сервер и сайт на этом компьютере» → панель **«SMS: одноразовые коды»** → «Настроить»:
   - Провайдер, логин / e-mail (для SMSC.ru и SMS Aero), ключ, имя отправителя;
   - **Лимит SMS в сутки** (по умолчанию 100) — защита от «накрутки» (см. ниже);
   - **Страны** — коды стран через запятую, по умолчанию `7` (Россия и Казахстан).

   «Сохранить» — ключ шифруется средствами Windows (DPAPI, как ключи ЮKassa и Lava.top), сервер перезапускается
   и подхватывает настройки. Строка состояния показывает «Включено: … · отправлено за сутки N / лимит».
5. **Проверить:** в той же панели введите свой номер и нажмите **«Отправить тестовое SMS»**. Если пришло — всё
   работает. Тестовое SMS тоже учитывается в суточном лимите.
6. Привяжите номер в своём кабинете на сайте и попробуйте «Войти по коду из SMS» в приватном окне браузера.
   *Исключение — аккаунт владельца (см. ниже).*

> Ключ провайдера — это деньги на балансе. Не отправляйте его в чат и никому не показывайте. Если ключ утёк —
> выпустите новый в кабинете провайдера и введите его в панели заново.

## Почему настройки только на ноутбуке, а не в админ-панели сайта

Тот, кто управляет SMS-провайдером, может перенаправить коды входа. Поэтому провайдер и ключ задаются **только**
в приложении владельца на ноутбуке и передаются серверу через переменные окружения. В админ-панели сайта этих
настроек нет: даже украденная сессия владельца на сайте не позволит перехватить чужие коды.

## Защита

- Код — 6 цифр (криптографически случайный), действует **5 минут**, после **5 неверных попыток** перестаёт
  действовать. В базе хранится только хэш кода с солью; код привязан к номеру и к цели (привязка / вход / сброс).
- Повторный код — не чаще раза в **60 секунд**, не больше **5 кодов в сутки** на номер.
- Ограничения по IP-адресу посетителя (адрес берётся из Cloudflare; раньше все посетители через публичную ссылку
  считались одним адресом — это исправлено).
- **Суточный бюджет SMS** на весь сервис (лимит в панели). Когда он исчерпан, коды не отправляются до следующих
  суток, вход по e-mail работает как обычно. Это защищает баланс от «SMS-накрутки» (злоумышленник заставляет
  сервис слать SMS на платные номера).
- **Только разрешённые страны** (по умолчанию +7).
- **Не раскрывается, зарегистрирован ли номер:** на запрос кода для входа или сброса сервер отвечает одинаково,
  а SMS отправляет только на номер, подтверждённый в каком-либо аккаунте.
- **Аккаунты владельца** (e-mail из «E-mail владельца») **не могут** входить и сбрасывать пароль по SMS — защита
  от перевыпуска SIM-карты мошенниками. Привязать номер можно, но входить нужно по e-mail и паролю (или по коду
  из письма, а пароль восстанавливать по e-mail — см. [docs/email-codes.md](email-codes.md)).
- Заблокированные аккаунты не получают SMS и не могут войти по телефону.
- Номера, коды и ключи не пишутся в журналы сервера; при ошибке провайдера в журнал попадает только его название
  и код ошибки.

## Переменные окружения (для запуска сервера вручную)

Приложение владельца задаёт их само. Для `npm run server:dev` можно указать вручную:

| Переменная | Значение |
| --- | --- |
| `TARKOV_SMS_PROVIDER` | `smsru`, `smsc` или `smsaero`; не задана — функции телефона выключены |
| `TARKOV_SMS_API_KEY` | SMS.ru: `api_id`; SMSC.ru: пароль / API-пароль; SMS Aero: API-ключ |
| `TARKOV_SMS_LOGIN` | SMSC.ru: логин; SMS Aero: e-mail аккаунта |
| `TARKOV_SMS_SENDER` | согласованное имя отправителя (необязательно) |
| `TARKOV_SMS_DAILY_LIMIT` | SMS в сутки на весь сервис, по умолчанию 100 |
| `TARKOV_SMS_PHONE_DAILY_LIMIT` | кодов в сутки на один номер, по умолчанию 5 |
| `TARKOV_SMS_COUNTRIES` | коды стран через запятую, по умолчанию `7` |

## Состояние проверки

Запросы к провайдерам написаны по их публичной документации (SMS.ru: `POST https://sms.ru/sms/send` с `json=1`;
SMSC.ru: `POST https://smsc.ru/sys/send.php` с `fmt=3`; SMS Aero: `POST https://gate.smsaero.ru/v2/sms/send`
с Basic-авторизацией). **Вживую они не проверялись** — среда разработки не имеет доступа к этим сайтам. Покрыты
модульными тестами с поддельным провайдером. Первая настоящая проверка — кнопка «Отправить тестовое SMS»; если
провайдер ответит ошибкой, её код появится в панели (например, у SMS.ru 200 — неверный `api_id`, 201 — не хватает
денег на балансе).

## Документы

Политика обработки персональных данных и согласие (сайт → «Реквизиты и документы») дополнены: номер телефона,
одноразовые коды, передача номера и текста SMS провайдеру. В тексте оставлено место для названия провайдера
(`[наименование: ООО «…»]`) — впишите выбранного провайдера и юридическое лицо по договору.
