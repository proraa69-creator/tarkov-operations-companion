# План реализации Tarkov Operator Desktop Beta

Дата: 25 сентября 2026 года  
Основание: `docs/superpowers/specs/2026-09-25-tarkov-desktop-data-progress-design.md`

## Результат

Переносимый Windows EXE на рабочем столе пользователя с полной загружаемой базой Tarkov, локальными профилями, импортом прогресса из журналов EFT, расчётом доступных заданий и быстрым завершением задания кнопкой слева.

## Принципы выполнения

- Каждый этап завершается автоматической проверкой и небольшим коммитом.
- Новая логика сначала покрывается тестом, затем подключается к интерфейсу.
- Данные каталога и пользовательский прогресс хранятся независимо.
- Импорт всегда проходит через предварительный просмотр и применяется атомарно.
- Журналы не покидают компьютер пользователя.
- Существующий браузерный прототип остаётся запускаемым во время разработки.
